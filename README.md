# 運転免許 学科試験トレーニング

兵庫・明石の仮免許／本免許学科試験向けの○×練習アプリです。NUMBER1〜5の通常問題とイラスト問題、特1〜特4を収録しています。

## iPhoneでアプリのように使う

このサイトはPWAとしてホーム画面から単独ウィンドウで開けます。初回に読み込むと、問題データと設問イラストを端末にキャッシュし、次回からオフラインでも使えます。

1. GitHubにこのフォルダーのアプリファイルをアップロードします。
2. リポジトリの **Settings → Pages** を開き、**Deploy from a branch**、`main`、`/(root)` を選んで保存します。
3. 公開された `https://<ユーザー名>.github.io/<リポジトリ名>/` をiPhoneのSafariで開きます。
4. **共有 → ホーム画面に追加**を選び、**Webアプリとして開く**をオンにして追加します。

Safariで一度サイトを開き、画面が読み込まれてからホーム画面に追加してください。


## 収録内容と採点

- 特1〜特4：冊子29〜32ページの問題文50問を文字データ化。30分、1問2点、90点以上を合格基準として採点します。
- 特5：元資料にありません。
- NUMBER1〜5：問題1〜90とイラスト問題91〜95を文字データ化し、原本イラストを個別に切り出して表示します。50分、問題1〜90は各1点、イラスト問題は3小問すべて正解で2点、90点以上を合格基準として採点します。

`index.html` はローカルでも開けますが、PWAのホーム画面追加とオフライン利用はHTTPSで公開した後に有効になります。


## 学習モード

- 試験モードは時間を計り、開始後は試験セットやモードを切り替えられません。終了後に正答と解説を確認できます。
- 練習モードは回答ごとに正誤を表示し、誤答の場合は該当セットの解答・解説資料を開けます。
